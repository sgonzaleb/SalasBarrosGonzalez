## Tema

Erling Haaland y la teoría de la violación de las expectativas: la condena de la excelencia y el impacto en redes.

## Descripción

Este sitio web presenta una pieza narrativa individual sobre cómo el rendimiento extraordinario de Erling Haaland afecta su nivel de interacción y menciones en plataformas digitales en comparación con jugadores de menor perfil.

La página integra texto narrativo, imágenes de apoyo y un análisis de la superposición entre el rendimiento deportivo y el impacto en redes.

## Proceso

Primero organicé el contenido en secciones narrativas, estructurando la página en HTML utilizando etiquetas como `head`, `body`, `header`, `main`, `img`, `a` y `footer`.

También incorporé la imagen de apoyo optimizada y configuré el despliegue automático mediante un flujo de GitHub Actions para apuntar correctamente a la subcarpeta del proyecto.
